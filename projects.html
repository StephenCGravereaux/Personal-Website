Behavioral Biometric Analysis for Task and Keystroke Inference

2025-2026

Undergraduate Research Project

Empirical study of smartwatch motion-sensor side-channel risk and a fixed-noise differential privacy defense built with IBM diffprivlib. Evaluates privacy-utility tradeoffs across multiple privacy budgets using public WISDM and Keystroke100 datasets. Featured by CBS6 Albany and UAlbany News.

  • Focus: Quantifying how fixed-noise DP affects both attacker accuracy and legitimate activity-recognition utility.
  • Core methods: Laplace-mechanism feature perturbation, typing-task inference, keystroke-dynamics user identification, ε-sweep evaluation.

CRYPTO Lab — Local RAG Assistant with Piper TTS

Late 2025

Undergraduate Research Project

A local assistant that pairs an LLM with RAG retrieval and Piper TTS so you can ask questions about sensitive documents without anything leaving the machine.

  • Focus: Fast local interaction with private operational documents.
  • Core methods: Retrieval grounding, local inference, and spoken response output.

Automated AI Twitch Chatbot

2023-Current

Personal Hobby Project

A Twitch chatbot I built for fun. It handles chat through the Twitch API, mixes local and hosted LLMs for replies, and speaks them out loud with a custom-trained voice. There's a GUI to drive the whole thing.

  • Focus: End-to-end AI automation for live-stream interaction.
  • Core methods: Twitch API integration, model routing, custom voice synthesis, and GUI control.
