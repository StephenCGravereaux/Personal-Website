Undergraduate Research

CRYPTO Lab — Local RAG Assistant with Piper TTS

Late 2025

A local LLM and text-to-speech workflow for asking questions about sensitive documents without sending anything to the cloud.

Outcome A working local assistant that answers from approved reference material and reads the answer aloud, fully offline, with no document data leaving the machine.

Project Overview

LLM + RAG + Text-to-Speech Assistant

Role: Undergraduate Researcher

I built this for local police departments that need a quick way to ask questions against their own approved reference material. It indexes those documents with a retrieval-augmented generation (RAG) layer, finds the relevant passages, and has a local LLM answer from them. Piper TTS reads the answer back out loud.

Approved Docs Department-approved reference material
→
RAG Index Documents embedded and indexed for search
→
Retrieve Pulls the passages relevant to the question
→
Local LLM Answers grounded in the retrieved context
→
Piper TTS Reads the grounded answer back aloud

The whole pipeline runs locally in a Docker container, so no document data leaves the machine.

Implementation Notes

Design Approach

  • Combined local LLM reasoning with text-to-speech output for faster operator interaction.
  • Integrated a RAG retrieval flow to ground responses in indexed source documents.
  • Kept the architecture lightweight to run effectively on standard hardware.
  • Used Docker to containerize the runtime for repeatable setup and cross-platform consistency.

Privacy and Repository Scope

Due to privacy and information sensitivity, only the text-to-speech and application-side integration system is public in the GitHub repository. No correlated operational documents, confidential source material, or agency-specific indexed data are included in the public codebase.
