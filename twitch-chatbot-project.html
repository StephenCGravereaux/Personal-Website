Project Overview

Live Streaming AI Assistant Pipeline

Role: Designer and Builder

A Twitch chatbot I built from scratch as a hobby project. It hooks into the Twitch API, generates replies through a mix of local and hosted LLMs, and speaks them out loud using a custom-trained voice. The point was mostly to see if I could get all of it running end-to-end and have it actually hold up on a live stream.

Twitch Chat Live messages pulled through the Twitch API
→
Model Router Decides between local and hosted models
→
LLM Reply Fine-tuned local Llama or hosted OpenAI
→
Voice Synthesis ElevenLabs API with a custom-trained voice
→
Live Stream Spoken aloud on the broadcast in real time

A custom GUI orchestrates and configures every stage.

Implementation

Key Components

  • Integrated Twitch Developer API keys for real-time chat ingestion and response flow control.
  • Implemented voice modulation/output using the ElevenLabs API with a custom-trained voice profile.
  • Used fine-tuned OpenAI models alongside a local fine-tuned Llama model for flexible response generation.
  • Built a custom training dataset of 100,000+ synthesized JSONL-formatted samples.
  • Created a GUI that ties together orchestration features, configuration controls, and runtime interaction.
